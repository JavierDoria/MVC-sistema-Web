# Sistema Web con ASP.NET Core MVC, Entity Framework Core y DTO

 Desarrollo de una aplicación web utilizando ASP.NET Core MVC sobre .NET 9, aplicando una arquitectura estructurada con Models, DTOs, Managers y Controllers.
Implementación de Entity Framework Core con DbContext y Migrations para persistencia de datos en SQL Server.
Uso de DTOs para transferencia segura de datos entre capas.
Creación de vistas Razor para la presentación de información en la interfaz web.

Esta implemantado tablas, busquedas,  y la exportacion de archivos.


## Tecnologías utilizadas
- ASP.NET Core MVC / .NET 9
- Entity Framework Core
- C#
- SQL Server
- jQuery/DataTables
- HTML5, CSS3
- Bootstrap
- DTO
- Razor Views
